# 📋 Користувацький сценарій (User Scenario)

### Основний сценарій: Купівля речей різних брендів в один кошик

* **Роль:** Авторизований покупець.
* **Контекст:** Користувач хоче підібрати кросівки Nike та футболку Zara для вечірньої прогулянки.

### Покроковий процес:
1. **Вхід на платформу:** Користувач відкриває головну сторінку маркетплейсу.
2. **Фільтрація за брендом:** Користувач натискає на бічну панель фільтрів, обирає чекбокс `Бренди` -> `Nike`.
3. **Вибір першого товару:** У сітці товарів обирає кросівки, вибирає розмір `42` та натискає кнопку `Додати в кошик`.
4. **Повернення до каталогу:** Користувач скидає фільтр бренду та обирає `Zara`.
5. **Вибір другого товару:** Знаходить чорну футболку, обирає розмір `L` та натискає `Додати в кошик`.
6. **Перевірка кошика:** Користувач переходит у кошик у верхній панелі сайту.

### Очікуваний результат:
У кошику одночасно відображаються два товари від абсолютно різних брендів (Nike та Zara). Загальна сума замовлення порахована коректно. Кнопка `Оформити замовлення` активна.
